# AP-3 Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship every AP-3 requirement that does not need Business Central changed.

**Architecture:** Journal composition stays a pure function in `src/lib/clr/clear-advance-erp-payload.ts` and is unit-tested. **Branch:** `feat/ap3-phase1` (cut from `feat/ap3-clear-vendor`).

**Baseline:** **692 tests pass** on `feat/ap3-phase1` (measured 2026-09-01). Never let the count drop below that.

**Never run `npm run build`** — the user's `npm run dev` owns `.next`. Use `npm run typecheck` and `npm test`.

/** HQ takes the head-office accounts; a PC branch takes only the "สาขา" ones. */
export function isHqBranch(branchCode: string | null | undefined): boolean {
  const b = (branchCode ?? "").trim().toUpperCase();
